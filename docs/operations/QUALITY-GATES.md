## GitHub Advanced Security gates (removed pending a decision)

`.github/workflows/codeql.yml` (CodeQL) and the `dependency-review` job that used to run inside `ci.yml` were removed on 2026-08-29: both require GitHub Advanced Security, which is not enabled on this private, organization-owned repository, and both failed unconditionally — including on the very first CI run, before any application code existed — with no code-level fix available. Whether to re-add them depends on a plan/billing decision (GHAS is not purchasable on GitHub Free for organizations) that belongs to whoever administers the `TDKSoft-Studio` organization, not to an agent. If GHAS becomes available, both can be restored from git history (`git log -- .github/workflows/codeql.yml`, and the `dependency-review` job in `ci.yml`'s history) with `actions: read` already added to the CodeQL workflow's permissions, since that fix stays necessary regardless.

## Parity definition

`task ci` mirrors the provider-independent primary CI job. `task ci:extended` adds network, SBOM, and browser gates. Container commands are functionally aligned with their CI job but require Docker/Trivy locally. The infrastructure repository must own Helm parity once its creation is authorized.

A `MANUAL_APPOINTMENT_ADAPTER_ONLY` contract result is a recorded phase-gate status, not schema-compatibility evidence against a pinned OpenAPI artifact. Automated accessibility results are necessary evidence only and never replace keyboard/screen-reader/manual expert review.

## Performance budget method

`PERFORMANCE_BUDGETS.json` caps the aggregate gzip size of App Router JavaScript and CSS emitted by the production build. It is not Core Web Vitals evidence; representative 75th-percentile journey measurements must replace or supplement it before release.
